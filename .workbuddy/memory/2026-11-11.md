## 修复：Q4 页左侧目录点了没反应（12:30）

现象：进 Q4 页后点目录（占比异常·三级分类 等），页面直接被踢回主看板，看着像「点击不了」。

### 根因（两处叠加）
1. 目录点击的**滚动兜底**里写了 `location.hash = href.slice(1)` → hash 变成 `#q4c-2`。
2. `applyQ4View()` 原来用 `/(^|.*#)q4$/.test(hash)` 判定，**只要 hash 不是 #q4 就当成离开 Q4** → 一次页内锚点就把 Q4 页关掉了（同时 `renderNav()` 换回 8 项主目录）。
   实测复现：点击后 `hash=#q4c-2 body=(空) navs=8`。

### 修法
- `applyQ4View()` 改为**只认明确信号**：hash 前缀 `q4` → 进 Q4；hash 为空 → 回主看板；**其它 hash 维持当前视图**（`on = now`）。
- 目录兜底不再动 hash，改 `window.scrollTo(0, top)` 瞬时跳；等待 350→600ms、阈值改 <4px。
- 跳转偏移从写死的 `-10` 改为读 `--nav-gap`（= 粘性筛选栏高度+10），和 `section.block{scroll-margin-top}` 用同一个值；
  新增 `#q4Block .q4card{scroll-margin-top:var(--nav-gap)}`，直接带 `#q4c-N` 打开也不会被筛选栏盖住。
- ⚠️ 无头 Edge **根本滚不动**（`scrollTo` 后 `scrollY` 恒 0），所以不能靠截图断言滚动；改用注入探针读 `location.hash / body.className / nav 数量` 判定视图是否被踢走。

### 回归用例（新增）
`test_dashboard.js` 的 Q4 用例加「视图切换」：`#q4`→进、`#q4c-2`→仍进、`#nav-sec-3`→维持、`''`→退出、`#q4`→再进，须 `true/true/true/false/true`。
为此给 DOM 桩补了 `document.body`（带 classList）与 `window.location`。断言里只能用字符串拼接（模板字符串坑）。
