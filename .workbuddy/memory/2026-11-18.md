## 12:11 修「负责人显示 +N / 跨两个业务负责人」
用户截图指出：墨西哥站 Q4「狗窝」的负责人显示「赵敏 +1」，与「负责人都按最新表、历史也统一」的要求不符。

**根因**：`q4Rows` 里 `m.own` 把**全窗口各期**的负责人 Σf1 累加，历史期的旧负责人票数被计入 →
`ownMore = 人数-1` 就弹出「+N」。实测墨西哥狗窝：全周期 李灌蒿(19) + 赵敏(935)，最新一期只有赵敏(76)。

**修复**（`dashboard_template.html` q4Rows）：
- 改成 `m.ownByP`（周期下标 → Map(负责人→Σf1)）；取「**最近有记录的一期**」里 Σf1 最大的那位，
  整组只出一个负责人；删除 `ownMore`（Q4 表格 / CSV 导出两处渲染同步去掉 `+N`）。
- 🔴 关键：不能用「全窗口累加最大」，否则历史旧负责人把票投回来（正是这次的 bug）。
- 顺带满足「两站点分开算负责人」：多场景置物架 MX=吴珍妮 / BR=蓝晓琳 各自独立。
