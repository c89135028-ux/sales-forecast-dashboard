## 修复：导出 CSV 不遵循「自定义列」
- 现象：自定义列只留 7 列，导出却是全部 17 列（用户截图对比表格 vs Excel）
- 根因：`exportTableCSV` 直接遍历 DOM 的 `th`/`td`，而隐藏列只是 CSS `display:none`，节点仍在
- 修复：读取 `<table data-hide="...">`（= 自定义隐藏列 ∪ 该表默认排除列，如 SKU 表默认藏 4 列），
  `keep(el)` 判据 `无 data-c 或 data-c 不在 hidden 中`；表头与数据行同一判据，保证列数一一对应
- ⚠️ 用 `data-hide` 而不是 `hideColsSet(tblKey)`，因为后者不含 SKU 表的默认排除列
- 回归测试 `out.导出跟随自定义列`：伪造 table 对象 + 替换 Blob/createElement/URL，断言「全量5列 → 隐藏2列后3列、表头数据都只剩 3 列」
- 顺带修正 `out.自定义列` 用例的 bug：原来写 `state.hideCols = new Set([...])`（应为对象 `state.hideCols[ctxKey(k)] = Set`），导致该用例从未真正隐藏过列；现可见列 17→14 才生效
- ⚠️ **测试代码写在模板字符串里，`\n` 必须写 `\\n`**，否则模板字面量会先转成真实换行 → `Invalid or unexpected token`
- 结果：`自定义列=可见指标列14(应为14)`、`导出跟随自定义列=全量5列/隐藏后3列/隐藏列已排除=true`、RUNTIME OK；已推送 62bf2a4
